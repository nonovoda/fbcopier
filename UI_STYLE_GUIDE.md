# UI STYLE GUIDE — FB BOOKMARKLET TOOLS

Единый стиль для всех внутренних bookmarklet-скриптов Facebook Ads Manager.

## 1. Общий принцип

Интерфейс должен выглядеть как компактный внутренний инструмент, а не как публичный SaaS-сайт.

Главные качества:
- быстро считывается;
- занимает мало места;
- не мешает работе в Ads Manager;
- выглядит аккуратно и единообразно;
- все действия понятны без длинных инструкций.

Базовый паттерн интерфейса:
заголовок → версия → настройки → главное действие → вторичное действие → лог → короткая заметка.

## 2. Язык интерфейса

Весь интерфейс на русском языке.

На английском допустимо оставлять только:
- название инструмента;
- технические названия;
- API-термины;
- названия сущностей Facebook.

Кнопки, статусы, подсказки, ошибки и логи писать на русском.

## 3. Визуальный стиль

Стиль: compact dark utility UI.

Использовать:
- тёмный фон;
- зелёный акцент;
- тонкие границы;
- компактные отступы;
- минимальные тени;
- плотную вертикальную структуру.

Не использовать:
- glassmorphism;
- сильные свечения;
- кислотные градиенты;
- большие декоративные карточки;
- иконки без необходимости;
- огромные отступы;
- сложные dashboard-сетки.

## 4. Цвета

Основные цвета задаются в `ui/core/tokens.js`.

База:
- фон модалки: `#0f1715`;
- фон поля: `#121f1b`;
- глубокий блок/лог: `#0b1210`;
- основной текст: `#e8fff0`;
- вторичный текст: `#99b3a6`;
- label: `#c7e0d2`;
- границы: `#2b433a`, `#2f4a40`;
- акцент: `#4dff8f`;
- успех: `#9bff7d`;
- ошибка: `#ff8f8f`.

## 5. Типографика

Основной шрифт:
`Inter, Segoe UI, Arial, sans-serif`.

Базовый размер:
`13px`, line-height `1.4`.

Заголовок инструмента:
- 32px;
- font-weight 800;
- цвет `#4dff8f`.

Версия/заметки:
- 11px;
- цвет `#99b3a6`.

Labels:
- 12px;
- цвет `#c7e0d2`.

Логи:
- 12px;
- monospace;
- `white-space: pre-wrap`.

## 6. Модалка

Все bookmarklet-интерфейсы строить как fixed-модалку по центру.

Параметры:
- ширина: `min(420px, calc(100vw - 24px))`;
- max-height: `calc(100vh - 40px)`;
- overflow: auto;
- padding: 14px;
- border-radius: 14px;
- z-index: 2147483647.

Если интерфейс большой, допустимо:
- ширина 520–720px;
- двухколоночная структура только при реальной необходимости.

## 7. Компоненты

### Header
- название слева;
- версия под названием;
- крестик закрытия справа сверху;
- крестик без фона.

### Fields
- full-width;
- background `#121f1b`;
- border `#2f4a40`;
- radius 9px;
- padding 9px.

### Primary button
Использовать только для главного действия.
- background `#4dff8f`;
- text `#052012`;
- font-weight 700.

### Secondary button
Для копирования, закрытия, дополнительных действий.
- background `#121f1b`;
- text `#e8fff0`;
- border `#2f4a40`.

### Log
У каждого долгого действия должен быть лог.
- background `#0b1210`;
- border `#22372f`;
- max-height 180px;
- scrollable;
- success green;
- error red.

## 8. UX-правила

- Повторный запуск открытого скрипта закрывает окно.
- Долгие действия блокируют основную кнопку.
- Ошибки показывать в лог, не только через alert.
- Результат должен копироваться одной кнопкой.
- Статусы должны быть короткими и понятными.
- Не перегружать интерфейс подсказками.
- В заметке снизу писать только важную информацию: безопасность, локальная обработка, мягкая нагрузка на API.
