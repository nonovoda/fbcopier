Meta Ads Import Helper

Campaign Cleaner

Загрузи CSV/XLSX экспорт кампании, очисти ID, статистику, старые ассеты и замени pixel/page/Instagram ID перед импортом. Всё обрабатывается локально в браузере.

Файл и настройки

Поддерживаются .csv, .xlsx и .xls. Для GitHub Pages сервер не нужен.
Формат JSON. Можно оставить пустым. Скрипт заменит значения в обычном тексте и внутри JSON-полей.
Строгий режим: скрипт автоматически очищает только ID уровней Campaign/Ad Set/Ad, удаляет системные метрики/даты, подставляет Pixel/Page/Instagram ID и ставит статусы в PAUSED. Креативы/объявления сохраняются.

Лог обработки

Campaign ID Ad Set ID Ad ID Creative ID Asset Feed ID Object Story ID Image Hash Video ID Stats
Файл не отправляется на сервер. Обработка идёт внутри браузера.
